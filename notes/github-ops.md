# GitHub ops (personal)

How I keep `AndrewTech2026` useful instead of empty.

## Cadence

- **Weekly:** 2–3 real commits (docs, tiny tools, fixes) — not empty churn.
- **Monthly:** one readable note or demo someone else could run.
- **Never:** fake green-square commits, secret keys, or private product dumps.

## Profile checklist

- [x] Bio states direction (AI products / agents)
- [x] Profile README explains who / what / where to look
- [ ] Pin 2–3 public repos in GitHub UI (Profile → Customize pins)
- [ ] Keep private work private; publish only sanitized lessons

## What goes public vs private

| Public | Private |
|--------|---------|
| Checklists, patterns, demos | Product source, investor docs |
| Learning notes | Live trading configs / keys |
| Reproducible scripts | Customer or internal ops data |
